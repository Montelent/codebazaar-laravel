CodeBazaar — Installation Guide

For buyers of the full CodeCanyon package (includes application code and, where provided, Composer vendor/ dependencies).

Quick path: Upload → point domain to public/ → open /install → activate license in Admin → configure payments & SMTP.

1. Server requirements

  • PHP 8.2+ (8.3 recommended)
  • MySQL / MariaDB
  • Extensions: BCMath, Ctype, cURL, Fileinfo, JSON, Mbstring, OpenSSL, PDO, Tokenizer, XML
  • Apache with mod_rewrite or Nginx equivalent
  • Writable storage/ and bootstrap/cache/

2. Upload the package

  1. Download the ZIP from CodeCanyon (Download → All files & documentation).
  2. Extract on your computer, then upload the project folder to your host (e.g. public_html/codebazaar/) via FTP/SFTP or File Manager.
  3. Prefer setting the domain document root to the public/ directory inside the project.

3. Web installer

  1. Visit https://your-domain.com/install
  2. Pass the requirements check
  3. Enter database credentials and site URL (the installer writes .env)
  4. Create your admin account
  5. Log in at /login

After a successful install, /install is disabled (404) for security.

4. License activation (required)

Most Admin features stay locked until you activate:

  1. Open Admin → License activation
  2. Paste your Envato purchase code (CodeCanyon → Downloads → License certificate / purchase code)
  3. Submit — the license is bound to the current domain
While locked you can still use Basic settings and Blog so you can brand the site and publish posts.

5. Recommended configuration

SMTP / email

Admin → Settings → SMTP. Choose Gmail, Outlook, Resend, Hostinger, or custom SMTP. Send a test email.

Payments

Admin → Settings → Payments. Enable Paystack, Monnify, Stripe, crypto wallets, etc. as needed.

Storage

Admin → Settings → Storage for local, S3, Backblaze, or iDrive uploads.

Cron job

* * * * * cd /path/to/codebazaar && php artisan schedule:run >> /dev/null 2>&1

6. Install with Composer (developers)

If your package was shipped without vendor/, or you prefer a clean install:

composer install --no-dev --optimize-autoloader
cp .env.example .env
php artisan key:generate
php artisan migrate --force
php artisan storage:link

7. Updating

  1. Back up files + database
  2. Upload changed files (or git pull if you deploy from Git)
  3. Run migrations from Admin → System tools (or SSH: php artisan migrate --force)
  4. Clear caches from System tools

8. Troubleshooting

ProblemWhat to try
Blank page / 500Check storage/logs/laravel.log; ensure APP_KEY is set; clear caches
404 on all pagesDocument root → public/; enable rewrite
Admin features lockedComplete License activation with purchase code
Composer PHP mismatchSwitch host PHP version to match the package (8.2+)

9. Support

Use the CodeCanyon item support tab or the contact method listed in the item description. Include your purchase code, domain, and PHP version when asking for help.
